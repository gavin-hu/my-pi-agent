Plan, then execute 先规划，再执行

A read-only planning mode turns a task into a reviewed plan file that the agent then follows step by step.
只读的规划模式把一次任务变成一份可审阅的计划文件，智能体随后按步骤执行。

①Start开始
/plan <task> --planCtrl+Alt+P enter_plan_mode model asks first
写之前，先只读
→
②Explore探索
read · grep · find · ls web_search · web_fetch git status && git diff subagent → read-only
只读：写不进去
→
③Plan计划
write_plan .pi/plans/…-<slug>.md Goal · Context · Approach Visual · Steps · Risks Verification at most 50 steps
唯一的写入
→
④Review审阅
aapprove 批准 rrefine 修改 wbrowser 浏览器 xdiscard 放弃 Esckeep 留存
唯一的关口
→
⑤Execute执行
steps → todo ## Goal → goal set_plan_stepsticks Verification last
批准之后才写入
↺ refine 修改 rewrites the same file · 重写同一份文件
↰ keep planning 继续规划 still read-only · 仍然只读
The plan file is the source of truth.
计划文件就是唯一依据。
A guard rail, not a sandbox.
只是护栏，不是沙箱。
