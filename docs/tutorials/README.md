# Tutorials

Eleven walkthroughs, one flow each, run against a real session: the commands you
type and the screen that answers. Every one assumes Pi and this pack are installed
([Install](../install.md)).

Read the first three in order — a task, the plan it turns into, and the goal that
outlives a turn. After that, take whichever group below matches the work in front
of you.

## Start here

1. [Track your first task](./first-task.md) — the task list working on a real job,
   and how to change the plan without touching it yourself.
2. [Your first plan](./first-plan.md) — one change from a read-only investigation to
   a plan you approve.
3. [Give the session a goal](./first-goal.md) — one objective across turns, answered
   when the planning question comes and finished against the task list.

## Take a change through

- [Your first board](./first-board.md) — one feature from backlog to done, through
  the approve and review signatures.
- [Work in a worktree](./first-worktree.md) — a task in its own checkout, then
  landing the branch safely.
- [Hand a task to another agent](./first-delegate.md) — a specialist in its own
  context window: alone, in parallel, or in a chain.
- [Run long work in the background](./first-background.md) — a job you are told
  about when it ends, and a watcher on a log.

## Read the project and the web

- [Browse your working directory](./first-browse.md) — quick open, previews, a diff,
  and a line reference, in a loopback page.
- [Search and read the web](./first-web.md) — ask for a fact, read one page, and pull
  out only the section you need.

## Come back, or leave the desk

- [Go back to an earlier prompt](./first-rewind.md) — restore the code, the
  conversation, or both, and see what the restore replaced.
- [Chat with your session from WeChat](./first-wechat.md) — pair one account to one
  session and answer it from your phone.

Every extension also has a page of its own, in the order the catalog lists them —
[All extensions](../extensions/README.md) — and each walkthrough is linked from the
page that owns the commands it uses.
